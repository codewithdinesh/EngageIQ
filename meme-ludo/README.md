# Meme Ludo

Local pass-and-play Ludo for 2 or 4 players on one phone. Captures, sixes, blocks, and home runs fire a short **Hostel Roast** meme: an original Hinglish caption plus a synthesized tone. No film audio, no accounts, no network.

This is a Phase 0 prototype. It is here to test whether the reaction is funnier than a normal dice click.

## Run

Requirements: Node.js 20 or newer, npm, and the [Expo Go](https://expo.dev/go) app on a phone (or a simulator).

```bash
npm install
npx expo start
```

Then:

- Phone: scan the QR code with Expo Go (Android) or the Camera app (iOS).
- Web (desktop playtest): press `w` in the terminal, or run `npx expo start --web`.
- Android emulator: press `a`. iOS simulator: press `i` (macOS only).

`npm test` checks the rules engine. `npm run typecheck` runs TypeScript.

## How a match works

1. **Home** — Play, or open “How memes work” for the rules and the eight roasts.
2. **Lobby** — Choose 2 or 4 players, edit names, leave Hostel Roast on, mute if you want.
3. **Board** — Pass the phone. The current player confirms, rolls, then taps a glowing token when they have a choice.
4. **Meme toast** — A banner and a sting (about 1.5 seconds or less) on the moments below.
5. **Match end** — Winner, the top memes from that game, replay the loudest one, a private playtest note, and play again.

Mute keeps the captions and drops the sound. The note on the result screen stays on the device.

## Rules used here

Classic Ludo, narrowed on purpose:

- Four colors on the board. **2 players** use the opposite corners, Red then Yellow. **4 players** go clockwise from the bottom-left: Red → Blue → Yellow → Green.
- Four tokens each. A **6** takes a token out of the yard and onto that color’s start square. The 6 is the exit, not six steps.
- Tokens move clockwise around the shared track, then up their colored column. You need the **exact** roll to enter the center.
- **Capture:** land on exactly one opponent token on a normal square and it goes back to its yard. You roll again.
- **Safe squares** are the four colored starts and the four ✦ squares. Nobody is captured there, and a crowd on a safe square is not a block.
- **Block:** two of your tokens on the same normal square. Opponents cannot land on that square or pass through it.
- **Extra turn** on a 6 and on a capture. If both happen, it is still one extra roll.
- **Three 6s in a row** cancel that turn. The third 6 does not move a token. The meme for that is “chaos sixes”.
- The **first player to bring all four tokens home** wins. The match stops there.
- The dice is uniform: each face from 1 to 6 is equally likely.

“Home” in a caption means the center. A captured token goes back to the **yard**, not the center.

## Meme triggers

| Moment | Caption |
| --- | --- |
| Capture | Majja aa gaya — seedha yard! |
| Got captured | Bhai ne kaat diya, wapas room. |
| Rolled a 6 | Chhakka! Ek aur chance, maggi bonus. |
| Third 6 in a row | Teen chhakke? Warden aa gaya — turn cancel. |
| One token reaches the center | Token ghar pahuncha. Room lock, chappal bahar. |
| No legal move | Rasta band hai bro. Agla player. |
| Land on a safe square | Safe zone. Tension mat le. |
| Win | Jeet gaya! Chai mere taraf se. |

Audio files in `assets/sounds/` are original sine-tone stingers generated by `scripts/generate-sfx.py`. They are not recordings from movies, songs, or other games. Regenerate them with `python3 scripts/generate-sfx.py`.

## Not in this build

Online rooms, accounts, custom uploads, voice chat, ads, payments, and posting to Instagram.
